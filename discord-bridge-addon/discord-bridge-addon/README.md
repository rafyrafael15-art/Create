# Discord Bridge (Meteor Client addon, MC 26.1.2)

Build: `./gradlew build` -> `build/libs/discord-bridge-0.1.0.jar` -> put it in `.minecraft/mods/` next to Meteor Client 26.1.2 and Fabric API.
Gradle wrapper files (gradlew, gradlew.bat, gradle/wrapper/*) are NOT included: copy them from MeteorDevelopment/meteor-addon-template.
